The goal: turn biological questions into computational systems that produce **testable predictions and traceable results**.

- **Quantitative systems:** time-series modeling, strategy evaluation, and automation with explicit risk controls.

## How I build

> “Architecture is intelligence made visible.”

- **Make assumptions visible.** Document what a model uses, what it predicts, and where its interpretation stops.
- **Evaluate the question that matters.** Choose baselines, data splits, and metrics that reflect the intended application.
- **Keep systems modular.** Separate data processing, models, evaluation, and interfaces so each can be inspected and improved.
- **Preserve the evidence.** Version configurations, track experiments, and keep the analysis behind the figures.
